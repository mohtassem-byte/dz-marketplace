# سوق DZ — DZ Marketplace

منصة جزائرية تجمع **المشاريع + الخدمات الجاهزة + السلع** في تجربة واحدة، موجهة للسوق الجزائري.

## التقنية
- Next.js + TypeScript
- React
- CSS responsive مع RTL
- جاهزة لاحقًا للربط مع Supabase
- جاهزة للنشر على Vercel

## مراحل البناء
1. Prototype وواجهة المستخدم
2. المصادقة والملفات الشخصية
3. الخدمات والمشاريع والسلع
4. المحادثات والإشعارات
5. الطلبات والتقييمات والنزاعات
6. الدفع والتوصيل بما يناسب الجزائر
7. لوحة الإدارة والتحليلات

## تشغيل محليًا
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.
